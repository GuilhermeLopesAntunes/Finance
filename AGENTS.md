# Instruções para IAs / Agentes de IA

Todas as IAs que operam neste projeto devem seguir as diretrizes definidas em [logs/GLOBAL_AI_INSTRUCTIONS.md](logs/GLOBAL_AI_INSTRUCTIONS.md).

## Regras Principais:
1. **Log Obrigatório:** Registrar todo processo de pensamento, análise e ações realizadas em arquivos `logs/log_AAAA-MM-DD.md`.
2. **Qualidade de Código:** Executar lint (`npm run lint`) e testes (`npm run test`) antes de concluir tarefas.
